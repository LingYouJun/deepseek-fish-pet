# 大肥鱼女仆桌宠 · 需求总览（v2）

## 1. 产品定位
陪伴 + AI 助手 + 英语口语练习。

## 2. 形态与平台
- 独立桌面程序（Electron），系统级悬浮桌宠，透明无边框置顶、可拖拽。

## 3. 形象
- 二创「吃白饭的大肥鱼」—— 蓝发鲸鱼女仆，二次元插画风。
- **立绘只留人物**：透明底，无背景 / 无文字 / 无身后大鲸鱼。
- 立绘随人设风格变（可爱风 → 可爱大肥鱼；忧郁风 → 忧郁大肥鱼等）。
- 点击桌宠有互动（台词 + 动作）。
- 素材由用户外包提供；工程做成可替换贴图（表情差分：待机/开心/害羞/惊慌等）。

## 4. 对话系统
- 两种入口：① 麦克风直接对话（语音）；② 独立聊天大窗口 + 头顶气泡式快捷对话。
- **语言：英语**（桌宠说英语、理解英语）。
- 每次桌宠说话 → 附小字「中文翻译 + 音标」。
- 每次桌宠说完 → 给 2 个预制回复（英文 + 翻译 + 音标），用户一键发送。
- 预制回复题库按词汇量分级（最低高中词汇，可上调）。
- TTS 语音朗读。

## 5. 记忆系统（三层）
- 短期：按聊天轮次。
- 中期：按会话次数。
- 长期：按天。

## 6. 人设系统
- 默认人设：蓝发鲸鱼女仆，傲娇、温柔、嘴硬。
- 用户可改人设（风格/语气/称呼/口头禅）。
- 隐藏设定：偷玩明日方舟，精通「集成战略」（肉鸽），对藏品/干员/分队/结局/坍缩范式等了如指掌；被戳穿玩游戏会嘴硬。

## 7. AI 助手
- 用户授权下操控电脑，含网页操控；权限分层，敏感操作二次确认。

## 8. 其它
- 与 DSH 会话联动。
- 位置 / 状态 / 心情持久化。
- 好感度 / 心情度系统（预算允许时）。

## 9. API
- 用户自选模型与接口，首次启动弹窗绑定；TTS 云端或本地。
