## 五、本机环境要点（踩过的坑）

1. **Electron 必须带 `--no-sandbox`**，否则起不来（`0x80000003`）。
2. **抓帧**：`--force-device-scale-factor=1`，或用 Chrome headless；★GDI `CopyFromScreen` 在 125% 缩放下会把 CSS 尺寸窗口放大 1.25 倍（曾导致"4.9%"的假结论）★。
3. 本机 125% 缩放：DIP 1536×864，物理 1920×1080（×1.25）。
4. Node→PowerShell 子进程在此环境**不可靠**（写出 0 字节/空文件）→ OCR 一律由 PowerShell 侧批量做（`app/scripts/gametest/shoot-ocr.ps1`，`WriteAllText` + `UTF8Encoding($false)`），Node 只读文件。
5. 启动她时：`Start-Process electron.exe <app路径>`（先 `Remove-Item env:ELECTRON_RUN_AS_NODE`）；★不要用 `.cmd`/`cmd /c`★。
