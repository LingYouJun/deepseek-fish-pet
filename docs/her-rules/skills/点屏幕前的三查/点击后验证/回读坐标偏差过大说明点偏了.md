# 点击后回读坐标与目标差很多 → 说明点偏了，要重新定位

## 现象
点击之后回读光标坐标，发现和**目标坐标差很多**（例如差了 960 像素）。
这不是"点得不够准"，而是**根本没点到目标上**——点偏了。

## 结论
回读坐标与目标坐标偏差过大（远大于正常误差范围）时，
**不要继续下一步**，也不要以为"点了就算数"。
这说明这一次点击落在了别的地方，后续操作全都会错位。

## 正确做法
1. 停下来，**重新定位目标**：重新 `uia_find` / `find_text` / `find_template` /
   `find_grid` / `strip_read` 当场量一次坐标（见「三查」第①条）。
2. 用新量到的坐标重新点击。
3. 点完再回读一次坐标核对，确认这次落在目标上，才继续下一步。

## 一句话
回读坐标和目标差一大截 = 点偏了 → 重新定位再点，别硬着头皮往下走。
