# 归一化坐标（move_norm 那种）不可直接用于点击

## 结论
视觉模型返回的**归一化坐标**（如 `move_norm` 用的 0~1 或 0~1000 相对值）
**不能直接拿去点击**。点击需要的是**绝对像素坐标**。

## 正确做法
1. 拿到归一化坐标后，先按当前屏幕分辨率换算成绝对像素：
   `x_px = x_norm * screen_width`，`y_px = y_norm * screen_height`
   （注意确认模型用的是 0~1 还是 0~1000 的刻度，别算错倍数。）
2. 换算出的像素坐标，仍要过一遍「三查」——尤其是**当场量**这一条，
   分辨率/窗口位置变了就要重新算。

## 报错绕行
`move_norm` 报 **"dbg is not defined"** 时，不要卡在这个函数上，
直接改用 `click` 传**绝对像素坐标**完成点击。

## 一句话
move_norm 的归一化值 → 先换算成绝对像素 → 再 click；
move_norm 报 "dbg is not defined" → 直接换 click 绝对像素坐标。
